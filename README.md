# Tony · 专业发型顾问

一个面向 AI 助手的发型咨询 Skill：结合本人照片、头发条件和日常打理习惯，推荐现实可行的发型，按需生成本人试发图，并整理能直接交给理发师的沟通卡。

## 能做什么

- **分析头发条件**：区分照片可见信息、用户自述和待确认事项。
- **推荐发型**：比较长度、刘海、分缝、轮廓、层次与维护负担，默认给出 2–3 个有实质差异的方案。
- **适配参考图**：拆解喜欢的发型，说明当前剪裁、造型和烫染分别需要什么条件。
- **生成本人试发图**：使用本人照片进行头发编辑，尽量保留人物特征与原有构图。
- **制作理发师沟通卡**：整理目标、长度轮廓、必须保留的部分、日常条件与现场确认项。

各环节都可以单独使用，不必走完整流程。

## 安装

本项目是由指令和参考资料组成的 Skill，无需安装程序依赖。宿主需支持加载 `SKILL.md`；照片分析需要图像理解能力，本人试发需要可用的图像编辑工具。

### Codex

将仓库克隆到个人 Skills 目录：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/cKnight107/tony.git ~/.agents/skills/tony
```

如果目录已存在，请先确认其中的内容。也可以下载仓库 ZIP，解压为 `~/.agents/skills/tony/`，确保 `SKILL.md` 位于该目录根部。

Codex 会自动发现新 Skill；未显示时重启 Codex。安装位置和加载方式见 [OpenAI 官方 Skills 文档](https://learn.chatgpt.com/docs/build-skills#where-to-save-skills)。

### 其他支持 Skills 的 AI 助手

把完整 `tony` 目录放入宿主支持的 Skills 目录，保留 `agents/` 和 `references/` 的相对路径。具体安装位置、调用方式和可用工具以宿主文档为准。

## 使用

在 Codex 中用 `$tony` 调用，并按需要附上本人照片或发型参考图。

**推荐发型：**

```text
请用 $tony 分析我的照片。我希望保留能扎起来的长度，
不接受漂发，每天愿意花 5 分钟打理。请推荐 3 个可行方案。
```

**适配参考图并试发：**

```text
请用 $tony。第一张是本人照片，第二张是喜欢的发型参考。
先判断当前长度能否实现，再生成一张本人试发图，说明需要哪些打理条件。
```

**整理理发师沟通卡：**

```text
请用 $tony，把刚才选定的方案整理成理发师沟通卡，
写清长度、刘海、层次、必须保留的部分，以及需要现场确认的事项。
```

只做文字咨询时可以描述头发条件。需要本人试发时，必须提供本人照片；搜索和图像生成取决于宿主提供的工具，不是本仓库自带的服务。

## 使用边界与资料来源

照片可用于讨论可见轮廓和长度，不能代替发丝粗细、实际密度、孔隙度、弹性或化学处理兼容性的现场评估，也不用于诊断头皮疾病或脱发。烫染可行性需由理发师结合头发状态、处理历史和必要测试确认。

试发图用于预览方向，可能出现人物特征或发型偏差，不保证与实际剪后效果一致。照片会交由所选 AI 宿主及其图像工具处理，请按相关服务的隐私规则决定上传内容；提交 Issue 或 PR 时请勿附上未经授权的他人照片。

两份 [发型设计](references/hair-design.md) 与 [头发可行性](references/hair-feasibility.md) 资料为原创提炼，列有职业资格机构、教学平台等来源及适用范围。MIT 许可适用于本仓库原创内容，链接指向的第三方资料仍遵循其各自的许可与版权要求。
